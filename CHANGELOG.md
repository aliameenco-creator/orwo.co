# Changelog

## 1.1.0 — 2026-10-15

- Fixed blog articles: every article now opens at /blog/<slug>/ without relying on rewrite rules (on the live site one article redirected to its image file and the other returned "page not found"). New articles you write also use /blog/<slug>/; mistyped article URLs show the 404 page instead of redirecting to a similarly named image.
- Redesigned article template: back link, date and reading time, wide cover image, drop-cap reading column, quote/list styling, previous/next article and "More from the blog", plus a thin reading-progress line.
- Blog listing: single-column cards with excerpts on phones, hover underline on titles.
- Social links (homepage and footer) are now round Facebook, X/Twitter, LinkedIn and Instagram icons, keeping their names for screen readers.
- Homepage "A Brief History of ORWO Film" is now three full-width chapters. Each passage brightens word by word as you scroll (off when reduced motion is requested).
- Contact page: embedded Google map below the form.
- Article section titles (headings in the original Strikingly posts) are now real headings instead of plain paragraphs.
- Sites already set up: Appearance → ORWO Setup → "Apply 1.1.0 updates" adds the map and converts the unedited section titles. Nothing else changes; each page keeps its previous version as a revision.

## 1.0.0 — 2026-10-12

- Rebuilt ORWO.co as a native WordPress block theme with the source navy palette, logo, photography, copy, Lora and Fira Sans fonts.
- Editable Home, Shot on ORWO, Gallery, Blog, Contact and Cookie Policy; two original articles as Posts; Site Editor header, footer and navigation.
- Original gallery, nine film references, responsive layouts, subtle animations, reduced-motion support and lightbox.
- Batched Media Library import, setup report, original article URLs, homepage setup, SEO metadata and preserved editor changes on reruns.
- Owned contact/newsletter forms with validation, spam guards, private enquiry records and configurable WordPress email notifications.
- GitHub release updater with package path, size, version and SHA-256 validation.

Hosted installation and real notification delivery remain user-run steps after upload.
