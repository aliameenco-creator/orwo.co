=== ORWO Film Community ===
Requires at least: 6.6
Requires PHP: 8.1
Version: 1.0.0
License: GPL-2.0-or-later

Upload this ZIP as a theme, activate, then Appearance > ORWO Setup > Complete ORWO setup.
Edit content in Pages and Posts. Edit header/footer/navigation in Appearance > Editor.
Set notification email in Settings > General. Form labels: Settings > ORWO Forms.
Submit a real test enquiry after installation and confirm its receipt.

Original pages, two articles, 12 gallery images, nine video references, responsive design,
reduced-motion support, repeatable import and SHA-256-verified GitHub release updater.
Full installation/editing notes: https://github.com/aliameenco-creator/orwo.co

Uses native WordPress blocks; Elementor and paid plugins are not required.
Source cookie policy needs review for the actual services enabled on your host.
External videos, shop and socials are links/references, not copied backend services.
